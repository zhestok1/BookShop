# BookShop — Bookstore REST API

Высокопроизводительный модульный бэкенд интернет-магазина книг, построенный на **Django REST Framework**.

Проект реализует полноценный e-commerce API с JWT-аутентификацией, управлением корзиной через сигналы, системой комментариев, транзакционно-безопасным оформлением заказов и расширенной админ-панелью.

---

## Возможности

- **JWT / Token Authentication** (SimpleJWT) с refresh-токенами
- **Модульная архитектура** (apps: users, books, cart, comments, payments)
- **Автоматическое создание корзины** при регистрации пользователя (Django signals)
- **Каталог книг** с категориями, авторами, фильтрацией, поиском и пагинацией
- **Корзина** — добавление, изменение количества, удаление товаров
- **Комментарии** к книгам с правами доступа
- **Checkout** с транзакционной безопасностью (создание заказа + позиций + платежа)
- **Кастомная админ-панель** Django
- **CORS** для фронтенда (Vite / React и т.д.)
- **Фильтрация, поиск и сортировка** через `django-filter`
- Поддержка медиафайлов (обложки книг, фото авторов, аватары)
